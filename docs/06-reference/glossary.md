# Glossary

Common terms and definitions used in Axtra Console.

---

## A

**AXTRA Copilot**
Real-time AI coaching system that analyzes conversations and provides 3-card guidance (Emotion, Leverage, Strategy) with suggested scripts.

---

## C

**Call Session**
A complete voice call record including metadata, transcripts, coaching history, and summary.

**Coaching Card**
One of three guidance cards (Emotion, Leverage, Strategy) shown during voice calls with status indicator and action items.

---

## L

**LangGraph**
Python framework for building agent workflows. Used in AXTRA Copilot for parallel analysis.

**LiveKit**
WebRTC infrastructure for voice/video calls. Provides media routing, data channels, and room management.

---

## P

**Persona**
AI customer character with specific traits, emotions, and behaviors for training simulations.

**Parallel Process**
Architecture where voice agent and supervisor run simultaneously for real-time analysis.

---

## R

**R2**
Cloudflare R2 storage for audio recordings. S3-compatible object storage.

---

## S

**Scenario**
Training simulation with specific context, difficulty, and learning objectives.

**Supervisor**
LangGraph workflow that analyzes conversations and generates coaching cards.

**STT**
Speech-to-Text. Converts audio to text using Google Gemini Realtime API.

---

## T

**Trigger**
Condition that causes AXTRA Copilot analysis (3 turns, 300 chars, or 30 seconds).

**TTS**
Text-to-Speech. Converts text responses to audio.

**Turso**
Edge database (libsql) used for storing user data, call sessions, and transcripts.

---

## V

**Voice Agent**
AI component that handles real-time voice conversation using Google Gemini Realtime API.

---

## Z

**Zustand**
State management library used throughout the frontend application.
